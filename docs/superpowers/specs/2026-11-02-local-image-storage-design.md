# 图标与图片集本地存储设计

## 目标与范围

为链接的亮色、暗色图标和图片集分别提供本地存储策略。图标默认开启，图片集默认关闭；已有设置缺少字段时使用上述默认值。开启后覆盖已有图片及后续新增、编辑的图片。站点 Logo、分类 Emoji、自定义按钮内嵌 SVG 不属于本次范围。

保留图片原网址，使用户能追溯来源，并在关闭本地存储时恢复外链。链接编辑弹窗内，亮色图标、暗色图标、图片集每个网址输入栏末尾放置无边框外链按钮，打开对应原图；无有效 HTTP(S) 来源时禁用。新窗口链接使用 noopener noreferrer。

## 方案比较与已选方案

1. **保留原网址及本地副本（用户已选择）**：使用设置决定实际展示地址，可恢复外链并复用已有文件，需要管理来源与副本映射。
2. 直接替换业务字段内的图片网址：结构简单，但需额外保存来源才能恢复，编辑、排序与迁移容易丢失对应关系。

## 数据与服务职责

- 设置新增 `localIcons: true`、`localGallery: false` 两个布尔字段，前后端默认值一致。
- 保留链接现有 `favicon`、`faviconDark`、`imageGallery` 字符串结构，以来源地址作为持久化规范；增加由 DataStore 管理的来源到本地文件映射。API 可在现有展示字段中返回策略解析后的地址，同时附带来源字段供编辑表单使用。提交表单仍提交原网址，避免将本地展示地址覆盖到来源。
- DataStore 负责全部 JSON 读写、枚举来源与更新映射；图片存储服务负责下载、解码、转换及文件写入。迁移结果按来源增量写入，禁止用旧快照覆盖迁移期间的链接编辑。
- 文件放入持久化数据目录 `uploads/icons/`、`uploads/gallery/`，以来源哈希命名 `.webp`。同来源同用途复用文件，写入先临时文件再重命名；映射存在而文件丢失时允许重新生成。
- 建议新增 Sharp 作为后端 WebP 转换依赖，保留透明度，不扩大图片尺寸；静态图保持尺寸并设合理像素上限，动态图尽量保留动画，无法解码时报告失败并保留来源显示。此依赖与具体编码参数为实施选择。

## 开关、迁移与失败行为

- 保存设置成功后启动后台批量迁移，不阻塞整个设置请求。仅管理员可触发与查询迁移；设置区显示进行中、成功和失败数量，并提供重试失败项的操作。
- 服务启动时按有效设置补齐缺失副本，使默认开启的图标策略覆盖已有数据，也能从上次中断中恢复。迁移限制并发，同一来源下载去重。
- 新建、编辑、移动或导入链接后按有效策略补齐副本；迁移未完成时显示原图，完成后前端刷新相应数据。只按当前仍有效的设置选择展示地址，关闭过程中完成的下载不会使已关闭的策略重新生效。
- 关闭策略立即恢复原网址，不删除副本；重新开启复用文件。删除链接不主动清理文件，本轮不增加磁盘回收机制。
- 单图失败不使整批或链接保存失败；失败状态可见且可重试，不写入无效映射，不替换原网址。原网址后来改变时使用新来源，不能复用旧来源映射。

## 下载与访问约束

复用现有安全下载能力，检查协议、DNS、重定向目标并限制超时、响应字节数和解码像素数，禁止访问本地或私网目标。只公开服务端生成的 WebP 文件路径，不放宽现有上传目录对任意文件的限制。SVG 等来源只能经解码转换后输出 WebP，不直接对外提供源文件。

## 验证

- 测试默认值、独立切换、来源保留与展示解析，以及图标双主题和图片集排序/删除后的映射正确性。
- 使用本地测试夹具和注入下载器验证真实 WebP 输出、透明度、失败回退、并发去重、重启补齐及关闭恢复。
- 验证禁止目标、重定向、大小与像素限制以及静态目录访问范围。
- 验证设置开关、迁移提示、编辑保存、原图按钮和画廊展示；运行相关后端测试及生产构建，对既有失败单独说明。
